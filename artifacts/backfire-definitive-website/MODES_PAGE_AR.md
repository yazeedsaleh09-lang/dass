# صفحة الأطوار — BACKFIRE

تاريخ: 2026-07-21 · الملفات: `apps/dasssite/src/modes/*`

## البنية

صفحة `/modes` تفصل بوضوح بين **الطور المتاح** و**العوالم القادمة**:

1. **بطاقة مميّزة (featured):** الطور الوحيد القابل للّعب الآن — **المجلس** (`majlis`، `THE ORIGINAL`) — مع زر **«ابدأ لعبة»** حقيقي يوصل إلى `/create`.
2. **ملاحظة صريحة (`modes-note`):** «العوالم القادمة معاينة تصميم… بلا شراء ولا تفعيل، وبلا زر ابدأ.»
3. **شبكة العوالم القادمة:** خمس بطاقات، كل واحدة بزر **«قريبًا» مُعطّل** (`<button disabled>`)، بلا سعر فعلي.

## الأطوار

| المعرّف | الاسم الظاهر | الاسم الفني | الحالة | الزر |
|--------|--------------|-------------|--------|------|
| `majlis` | المجلس | THE ORIGINAL | متاح الآن | ابدأ لعبة → `/create` |
| `siege` | هجوم العمالقة | THE LAST WALL | قريبًا | قريبًا (مُعطّل) |
| `classroom` | لعبة الأصدقاء | THE TRUST GAME | قريبًا | قريبًا (مُعطّل) |
| `orbit` | كايجي | THE EDGE | قريبًا | قريبًا (مُعطّل) |
| `blackout` | كود غياس | THE COMMAND | قريبًا | قريبًا (مُعطّل) |
| `hotel` | جوجوتسو كايسن | THE CURSE | قريبًا | قريبًا (مُعطّل) |

## صفحة تفاصيل الطور `/modes/mode?id=<id>`

تعرض الاسم، السطر، الخبيئة، الوصف، المواصفات (لاعبون/مدة/توتر/حالة)، وثلاث «لحظات» تعرض إيقاع الجولة. زر الفعل يتبع نفس منطق الحالة: «ابدأ لعبة» للطور المتاح، و«قريبًا» مُعطّل للبقية. المعرّف غير الموجود يعرض حالة فارغة آمنة.

## الفن

كل الأغلفة (`covers.ts`) رسوم SVG تجريدية أصلية تعبّر عن الفكرة الدرامية عبر أشكال وخطوط وحالات تلفزيون/جوال — **بلا شخصيات أنمي أو شعارات أو لقطات**.

## التحقّق البصري

- سطح المكتب (1280): البطاقة المميّزة + شبكة العوالم بثلاثة أعمدة.
- الجوال (390 و 320): البطاقات تتراص عموديًا، الأسماء العربية تظهر كاملة، أزرار «قريبًا» مُعطّلة ظاهرة.
- لا overflow أفقي عند 320px (عرض المستند = 320).
