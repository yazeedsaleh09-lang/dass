# نظام العواقب — BACKFIRE

الهيكل المفاهيميّ: نيّة ← التزام ← تفاعل خفيّ ← إشارة علنيّة ← اقتراب العاقبة ← أثر ← شرح سببيّ ←
ندبة باقية ← ضغط مستقبليّ. هنا مطابقته على القواعد الفعلية (`engine.ts`)، مع سلسلة سببيّة كاملة مُتحقَّقة.

## سلسلة سببيّة كاملة مُتحقَّقة (من `bfcheck` على البذرة `20260720`)
1. **الاختيار**: الغرفة تنتخب المُشغِّل ⇒ الصدى يلتصق به (بطاقة «الاختيار الأول»).
2. **التفاعل**: فهد يعطّل نورة ⇒ `disruptChangedCarrier = true` ⇒ تغيّرت هوية الحامل (بطاقة «التدخّل الخفي»).
3. **المسار المُبدَّل**: نقل دعم (بطاقة «المسار المُبدَّل») + انكشاف الصدى ⇒ التهديد يشتدّ (`echoExposed`).
4. **الوجهة + الحماية**: المحوِّل يوجّه الصدى إلى لاعبٍ اختار الحارس حمايته بالضبط.
5. **الارتداد**: `outcome = 'backfire'` ⇒ `finalTargetId = redirectorId` ⇒ رجع الصدى إلى المحوِّل نفسه.
6. **الأثر الباقي**: `world.echoHolderId = finalTarget`، `echoStatus = 'resolved'`، والتلفاز يضع `final-hit` على العُقدة.
7. **النتيجة**: النفوذ يُحسب من الأهداف؛ التعادل يُكسر بـ `threatContribution` ثم `successfulActions`.

**الجملة السببيّة (مُولّدة، مُتحقَّقة):**
«رجع الصدى إلى ⟨المحوِّل⟩ لأن الوجهة كانت ⟨س⟩ تحت حماية ⟨الحارس⟩.» + سطر الأصل «بدأ الصدى مع اختيار
⟨المُشغِّل⟩ مُشغِّلاً، واشتعل حين حمل صاحبُه النواة بلا حماية.»

## الذاكرة الدائمة (ما يبقى مرئياً)
- **مقياس التهديد** يبقى مرفوعاً بصرياً + سمعياً (سرير الصوت يتغيّر مع التهديد — `sfx.setThreatBed`).
- **رقاقة الصدى** (`#echochip`) تحمل اسم صاحب الصدى وحالته طوال المباراة.
- **`final-hit`** يبقى على عُقدة اللاعب الذي نزلت عليه العاقبة حتى شاشة النتائج.
- **الكشف النهائي** يُلخّص السلسلة في جملة واحدة تظهر أيضاً على شاشة نتائج الجوّال والتلفاز.

## توصية مستقبليّة (لم تُنفَّذ — تتطلّب قراراً بصريّاً)
«ندبة» أوضح تبقى بين الجولات: خطّ علاقة مكسور بين مُعطِّلٍ وضحيّته، أو وسم «خانه» يُشار إليه في جولةٍ
لاحقة. قيمة عالية للذاكرة الاجتماعية، لكنها تغيير تلفزيونيّ يحتاج تحقّقاً بصرياً بشرياً.
