# BACKFIRE — التقرير النهائي (تمرير تصميم اللعبة)

## 1. الحكم التنفيذي: **GO مشروط**
اللعبة قويّة بنيوياً، والتعديلان مُنفَّذان ومُتحقَّقان آلياً بالكامل. الشرط الوحيد المتبقّي: **جلسة الخمسة
لاعبين الحقيقيّة** لإثبات البوابات العاطفية التي لا تُؤتمت. لا يوجد ما «يجب إصلاحه قبل الأصدقاء» — الشرط
هو جمع الدليل البشريّ، لا إصلاح عطل.

## 2. الأسئلة الجوهريّة (بصدق)
- هل القرارات ثقيلة؟ **نعم بنيوياً** — بعد إزالة الخيار الوهميّ، لا هدف يُمنح دون قرار (مُثبَت).
- هل يتوتّر اللاعب قبل النتيجة؟ **مُصمَّم لذلك** (تجميد/صمت/عدّاد أقفال)؛ الشدّة الفعليّة = دليل بشريّ.
- هل الندم ناتج من قراره؟ **نعم** — المحرّك يتتبّع من غيّر النتيجة، والكشف يربطها بالقرار.
- هل التلفاز يُشعرهم أنهم داخل لعبة؟ **مُخرَج سينمائياً** ومُتحقَّق أنه يعرض ويُحرّك؛ «الإحساس» بشريّ.
- هل كل حدث يغيّر العالم أمامهم؟ **نعم** — تهديد/صدى/`final-hit` يبقون مرئيين.
- هل الكشف حدث سينمائيّ؟ **نعم**، وصار تكيّفياً يحذف الحشو ويصون بيت الارتداد.
- هل يفهمون كيف أثّرت قراراتهم؟ **نعم** — سلسلة سببيّة + جملة واحدة (مُتحقَّقة).
- هل تصنع قصّة يتذكّرونها؟ **البنية تصنعها**؛ التذكّر الفعليّ = دليل بشريّ.
- هل يوجد سبب للإعادة؟ **نعم** — أهداف مختلفة كل مباراة + لا فوز تلقائيّ + «جولة ثانية» في مكانها.

## 3. نتائج الأساس (مصنّفة)
- **تصميم اللعبة**: خيار وهميّ في الجولة 1 (عولج).
- **الكشف**: حشو «لا شيء حدث» يميّع الذروة (عولج بالتكيّف).
- **العاطفة/التلفاز/الصوت/الحركة/متعدّد اللاعبين**: قوّة قائمة، لا أعطال — راجع `council/`.

## 4. تغييرات تصميم اللعبة المُنفَّذة
### (أ) هدف الجولة 1: `not_operator` → `minority`
- **قبل**: «لا تكن المُشغِّل» — يفوز تلقائياً لغير المُرشَّحين (~٣/٥ مباريات)، صفر وكالة.
- **بعد**: «كن مع الأقلية — صوّت للاسم الذي لن يصير مُشغِّلاً»؛ الفوز = تصويت خاسر في جولة غير متعادلة.
- **لماذا**: البوابة 15 (لا خيار وهميّ) + خلق حافز خيانة صريح لكلّ اللاعبين.
- **الإحساس المتوقّع**: «أنا اخترت أضلّل الغرفة» بدل «فزت بلا ما أسوّي شي».
- **التحقّق**: اختبارا وحدة (وكالة حقيقيّة بمباراتين بنفس البذرة؛ لا فوز عند التعادل) + `bfcheck` (النفوذ = الأهداف).

### (ب) الكشف النهائي: ثابت → تكيّفيّ
- **قبل**: ٥ بطاقات دائماً، بينها «لم يقع أي تعطيل/لم يُنقل دعم/بلا حماية».
- **بعد**: `first_choice` + العاقبة دائماً؛ التدخّل/التحويل/الحماية تظهر فقط إن حدثت؛ الترتيب السببيّ ثابت؛
  الجملة + الأصل أرضيّة وضوح.
- **لماذا**: البوابة 11 (كشف سينمائيّ لا جدول) + عدم إخفاء أيّ سبب حاسم.
- **التحقّق**: 3 اختبارات وحدة (ترتيب/اختصار/إبقاء فعلٍ بلا أثر) + `bfcheck` (عقد جديد) + `bfbrowsercheck` (يُعرَض في Chrome).
